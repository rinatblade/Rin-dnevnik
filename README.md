# Rin-dnevnik

Личный дневник для Android: запись текстом или голосом, фото и видео дня, дата, время и погода на главном экране, список всех дней.

- 10 тёмных тем с градиентом и 5 светлых
- 40 русских шрифтов (скачиваются при сборке скриптом `scripts/fetch_fonts.py`)
- Погода: Open-Meteo (температура, ветер, осадки, анимированный значок)
- Каждый день хранится отдельно на устройстве

APK собирается автоматически на GitHub Actions и появляется в разделе **Releases**.
